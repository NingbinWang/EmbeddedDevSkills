# 性能分析报告模板

在最终答案中使用此结构。保持简洁，但不要省略结论部分。

## 问题现象

- 用户观察到的现象
- 相关时间窗口
- 使用的命令或相关证据

## 各领域证据分析

### CPU

- 全局系统级证据
- 进程级证据
- CPU是否为主要、次要问题，或非主要问题

### 内存

- 全局系统级证据
- 进程级证据
- 内存是否为主要、次要问题，或非主要问题

### I/O

- 全局系统级证据
- 进程级证据
- I/O是否为主要、次要问题，或非主要问题

### 网络

- 全局系统级证据
- 进程级证据
- 网络是否为主要、次要问题，或非主要问题

## 结论

明确陈述以下三项内容：

1. **主要瓶颈**：CPU、内存、I/O或网络
2. **瓶颈层面**：内核空间或应用程序空间
3. **触发进程**：主要的应用程序进程，或若问题无法归因于用户空间进程则标注为`未识别`
